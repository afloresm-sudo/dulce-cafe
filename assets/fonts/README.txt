Dulce Café Typography Assets
=============================

This directory contains the official typography families defined in the style guide:
1. Cormorant Garamond (Christian Thalmann / Catharsis Fonts) - SIL Open Font License (OFL)
   - Used for main headings (H1, H2, H3), brand title and hero accents.
2. DM Sans (Colophon Foundry, Jonny Pinhorn) - SIL Open Font License (OFL)
   - Used for body copy, interface buttons, navigation and data metrics.
3. Parisienne (Astigmatic) - SIL Open Font License (OFL)
   - Used for hand-lettered artisanal script details and bakery card tags.

Styles included:
- static/CormorantGaramond-Medium.ttf
- static/CormorantGaramond-SemiBold.ttf
- static/CormorantGaramond-Bold.ttf
- CormorantGaramond-VariableFont_wght.ttf
- static/DMSans-Regular.ttf
- static/DMSans-Medium.ttf
- static/DMSans-SemiBold.ttf
- DMSans-VariableFont_wght.ttf
- Parisienne-Regular.ttf

Usage:
These fonts can be loaded locally via CSS @font-face declarations in src/css/styles.css or src/style/style.css, providing 100% offline support without external network dependencies.
